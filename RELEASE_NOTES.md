# Edge Travel v0.1.0-alpha

Первый публичный альфа-релиз Edge Travel.

Edge Travel превращает край локальной карты RimWorld в путь к соседним областям. Колонист в режиме призыва может дойти до края карты и перейти на соседний мировой тайл. Посещенные соседние области сохраняются и восстанавливаются при возвращении.

## Главное

- Переход через края локальной карты колонистами в режиме призыва.
- Создание соседних локальных областей на основе соседних мировых тайлов.
- Сохранение посещенных областей через внешние XML-архивы.
- Восстановление архивированных областей при возвращении.
- Отслеживание состояния областей через реестр внутри сохранения.
- Метаданные RimWorld 1.6, зависимость от Harmony, превью, README и черновик Workshop-описания.

## Текущие ограничения

- Ранняя альфа-версия: используйте тестовые сохранения.
- Переход пока работает для колонистов в режиме призыва.
- Соседние области видны на мировой карте как объекты Edge Travel.
- Диагностика доступна только при включенном режиме разработчика.

## Требования

- RimWorld 1.6
- Harmony
